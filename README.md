MY PYTHON CALCULATOR
====================

About the Project
-----------------
This is a simple calculator program made using Python.

The program takes two numbers from the user and allows the user
to perform four basic mathematical operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

Features
--------
- Takes numbers as input from the user
- Performs basic mathematical calculations
- Uses if, elif and else statements
- Handles division by zero
- Shows the final answer to the user
- Easy to understand for beginners

Concepts Used
-------------
- Variables
- Input and Output
- float data type
- Arithmetic operators
- Conditional statements
- if-elif-else
- Comparison operators

How to Run
----------
1. Make sure Python is installed on your computer.
2. Open the Python file.
3. Run the program.
4. Enter the first number.
5. Enter the second number.
6. Select an operation from 1 to 4.
7. The calculator will display the answer.

Example
-------
Enter first number: 10
Enter second number: 5

Choose what you want to do
1 - Add
2 - Subtract
3 - Multiply
4 - Divide

Enter your choice: 1

You chose addition
Answer = 15.0

Note
----
This project is made as a basic Python programming exercise
to understand input, output, operators and conditional statements.
